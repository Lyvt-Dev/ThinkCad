# ThinkCad 1.2.6 implementation record

Base: main 75ba376 (published v1.2.3). Its release and all platform jobs
completed before this branch was created. Initial integration was a fast-forward;
there were no merge conflicts. Preserve the existing Qt Widgets editor and SDK.

Implementation sequence:
1. Project execution mode (legacy projects remain Simulation), board profiles,
   data-defined modules and local component packages.
2. Extend the existing I2cDevices/Wire implementation; add SPI register devices,
   UART timing/routing, GPIO interrupts and sensor adapters. Bounded bus traces.
3. Native settings groups and bus/pin tools; source debugging through optional
   local GDB, without replacing the normal native sketch runner.
4. Explicit LAN host/join, authenticated local sessions, live circuit/code edits,
   three-way conflict handling with preserved local changes. No external service.
5. Compatibility and end-to-end tests, examples, performance/memory checks,
   six-language UI additions and an honest device/protocol support matrix.
6. Re-fetch main, minimally resolve and record conflicts, build all packages,
   wait for any other release, then publish 1.2.6 from the tested commit.

The Emulation mode models peripheral registers, protocol transactions and virtual
bus timing. Native sketches execute on the host CPU; MCU instruction sets are not
claimed to be emulated. GDB inspects the native sketch, while board/peripheral
register inspection shows the modeled device state.

Keep source changes incremental. No login, cloud account/server, Electron,
mandatory online component catalog, or macOS support.

## Completed development checkpoints

- Board profiles, project format 4 / execution mode, data-only local packages,
  portable embedded descriptors and physical module rendering are committed.
- Register devices and physical SPI bus pass core and native-library tests for
  BME280, MPU6050 and MFRC522 in both modes. Libraries are pinned with individual
  source SHA-256 values and upstream licenses under `sdk/vendor`.
- Grouped native settings persist and apply execution defaults, editor font/tab/
  wrapping, refresh limits, local component directory and shortcut choices.
  Cancel/save/reopen behavior is tested; existing projects keep their mode.
- DHT / DS18B20 physical bus core and native-library tests pass in both modes.
  The test event loop now pumps at 1 ms rather than 10 ms to avoid adding an
  artificial 10 ms IPC delay to each 60 µs 1-Wire slot. Sensor commands reuse the
  circuit state already refreshed by GPIO/time/input changes.
- Latest fetched main remains 75ba376, with no incoming commits or running release
  workflow. No version bump, tag or release push has been performed.

The first broad test run passed 27/28 tests. The rendering test had overwritten
the default model of a newly added module with an empty string; the fixture now
preserves defaults. Its rerun completed with one traffic-light sketch startup
timeout while native compilers were running concurrently. Recheck that case
without competing builds before considering the suite green.

UART/interrupt routing, HC-SR04/NeoPixel/L298N runtime, bus/pin debugger tools,
source debugging, LAN collaboration and final translations/release remain open.

Checkpoint validation: full Debug build succeeded; all 29 CTest tests passed
