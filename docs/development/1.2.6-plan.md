# ThinkCad 1.2.6 implementation record

Base: main 75ba376 (published v1.2.3). Its release and all platform jobs
completed before this branch was created. Initial integration was a fast-forward;
there were no merge conflicts. Preserve the existing Qt Widgets editor and SDK.

Implementation sequence:
1. Project execution mode (legacy projects remain Simulation), board profiles,
   data-defined modules and local component packages.
2. Extend the existing I2cDevices/Wire implementation; add SPI register devices,
   UART timing/routing, GPIO interrupts and sensor adapters. Bounded bus traces.
3. Native settings groups and bus/pin tools; source debugging through optional
   local GDB, without replacing the normal native sketch runner.
4. Explicit LAN host/join, authenticated local sessions, live circuit/code edits,
   three-way conflict handling with preserved local changes. No external service.
5. Compatibility and end-to-end tests, examples, performance/memory checks,
   six-language UI additions and an honest device/protocol support matrix.
6. Re-fetch main, minimally resolve and record conflicts, build all packages,
   wait for any other release, then publish 1.2.6 from the tested commit.

The Emulation mode models peripheral registers, protocol transactions and virtual
bus timing. Native sketches execute on the host CPU; MCU instruction sets are not
claimed to be emulated. GDB inspects the native sketch, while board/peripheral
register inspection shows the modeled device state.

Keep source changes incremental. No login, cloud account/server, Electron,
mandatory online component catalog, or macOS support.
