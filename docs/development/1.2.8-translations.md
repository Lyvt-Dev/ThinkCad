# ThinkCad 1.2.8 translations

The interface supports German, English, Russian, Ukrainian, Spanish, French,
Italian and Portuguese. Existing translation keys retain the four-language
catalog; the additional catalog contains Italian/Portuguese entries for the
same English keys. The German/English mapping remains the canonical source.
Tests check catalog coverage, nonempty values, numbered placeholders and live
switching. User code, project names and filenames are not translated.

Italian and Portuguese drafts were generated locally with CTranslate2 and
SentencePiece, then corrected for navigation labels, software terminology,
source symbols, whitespace and placeholders. No translation model, translation
service or external translation request is part of the application.
